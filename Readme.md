# Weather Bot REST API

This is a REST API built with Node.js and Express that provides weather information using the OpenWeatherMap API. It is designed to work with DialogFlow ES for natural language interactions.

## Features
- Current weather lookup
- Weather forecast for up to 7 days
- Integration-ready with DialogFlow ES webhook

## Setup

1. Clone the repo or download the code.
2. Run `npm install`
3. Replace the OpenWeatherMap API key in `app.js`
4. Start the server using:

```bash
node app.js
